# 작업 보고

실행 도구에서 관찰한 작업 식별자와 상태를 읽는다. 준비·진행·실패·검증·리뷰·배포를 구분하고 알려지지 않은 값은 미확인으로 남긴다. 읽지 못한 출처(하위 에이전트 목록, 작업 대기열 등)는 읽지 못했다고 밝힌다.
현재 목표에 필요한 최신 변경만 요약한다. 모델·추론은 실제 요청 설정과 관측 가능한 실행값을 구분한다. 시간·토큰은 도구가 제공할 때만 보고한다. 사용자가 볼 필요 없는 로그와 내부 상태 용어를 답변에 나열하지 않는다.
보고서·슬라이드·표 같은 산출물은 생성 도구의 결과 항목과 실제 파일을 열어 확인한 뒤 완료로 보고한다. 종료 코드가 0이어도 렌더링·재계산 결과 항목이 실패이면 미확인으로 둔다. 렌더링 이미지는 하나씩 확인한 뒤 통과로 보고한다.
