# 장기기억

## 역할 설명과 실제 적용 확인

- 기억을 설명할 때 실행기 기본 기억(새 세션에 전달되는 핵심 사실), 과거 대화 검색(이전 상세 기록 회수), 스킬(재사용 절차), 프로젝트 문서(현재 계약·상태와 근거), GAM(프로젝트 범위로 검색할 결정·경험)을 구분한다. GAM 건수에는 연결된 Vault와 원본·색인 범위를 붙여 보고한다.
- 스킬 설치·MCP 연결·후보 저장·승인 활성화·검색 성공을 각각 확인한다. 스킬과 프로젝트 문서가 GAM 기억으로 이어지는 자동 절차는 실제 설정과 실행 근거로 확인한다.
- 저장 자동화를 요청받으면 대상 지식과 승인 범위를 먼저 정한다. 확정한 결정·규약·검증된 해결책의 핵심 요약과 출처를 후보로 삼고 프로젝트 문서를 정본으로 유지한다. 현재 질문이나 추천만으로 상시 저장 승인을 추정하지 않는다.
- 저장 권한을 받은 뒤에는 memory_remember로 후보를 만들고 승인 절차를 거쳐, 해당 프로젝트로 제한한 memory_search 또는 memory_context에서 실제로 회수되는지 확인한다. 연결 성공만으로 지식 축적 완료를 보고하면 이후 세션이 빈 저장소를 반복 조회하게 된다.

## 사용

작업 시작에 관련 과거 결정이 필요하면 GAM memory_context 또는 memory_search를 사용하고 현재 소스와 충돌 여부를 확인한다. 프로젝트의 절대 경로와 계정 범위를 전달한다.
사용자의 저장 요청 또는 승인된 기록 절차 안에서만 memory_remember로 후보를 만든다. 출처, 적용 범위, 확인 날짜를 포함하고 비밀값·원문 대화·추측을 기억으로 승격하지 않는다. 후보와 활성 기억을 구분하며 승인 근거가 있어야 활성화한다.
개인·회사 지식은 project 범위로 저장한다. GAM의 global/organization 표시는 강제 격리 장치가 아니므로 계정 경계 자료를 거기에 승격하지 않는다. 관련 없는 프로젝트 결과가 나오면 사용하지 않고 격리 검사 실패로 보고한다. 대체된 결정은 새 결정과 연결한다. 삭제 요청은 검색 제외와 원본·백업 삭제를 구분한다.
