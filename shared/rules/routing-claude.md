## 모델 라우팅 (Claude Code)

- 복합 작업의 독립 단위를 위임할 때 작업 성격에 맞는 분류를 `~/.claude/agent-setup/routing.json`에서 고른다. 일반 답변과 작은 수정은 현재 대화에서 처리한다.
- 분류의 `chain`을 앞에서부터 사용한다. `executor`가 `route-*`인 항목은 해당 하위 에이전트를 호출한다(모델과 추론은 에이전트 파일에 있다). `executor`가 `codex:codex-rescue`인 항목은 codex 스킬 절차로 Codex 플러그인에 `--model <model> --effort <effort>`를 붙여 넘긴다.
- 항목이 모델 사용 불가·한도·인증 오류로 실패하거나 Codex 결과가 비어 있으면 같은 작업을 다음 항목으로 넘긴다. 마지막 항목도 실패하면 오류 내용을 보고한다.
- 위임 결과를 보고할 때 분류, 요청한 모델·추론, 실제로 실행된 항목을 적는다. 사용자가 모델을 지정하면 그 모델을 사용한다.
