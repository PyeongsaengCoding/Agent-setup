# 설치 완료 기준 (AI용)

이 문서는 Claude Code·Codex·Hermes에 **갖춰져야 할 결과**를 정한다. 설치와 검증의 도구·순서·방법은 담당 AI가 대상 컴퓨터, 계정, 실행기, 공식 문서를 보고 정한다. 실행기별 구성 항목은 해당 `INSTALL_FOR_AGENTS.md`를 따른다.

## 확인할 결과

| 영역 | 완료로 인정할 결과 |
|---|---|
| 원본 | 적용한 Agent-setup 버전의 검사 결과가 통과한다 |
| 적용 | 사용자가 선택한 실행기와 프로필의 실제 설정에 전역 지침·라우팅·스킬·도구가 반영되고, 기존 사용자 설정과 충돌한 항목의 처리 결과가 확인된다 |
| 발견 | 사용자가 작업할 앱 또는 CLI의 새 세션에서 설치한 지침·스킬·도구와 라우팅 대상이 보인다 |
| 동작 | 해당 세션의 실제 모델 응답·위임, CodeGraph·GAM 응답, 선택한 브라우저·UI 기능이 실행기별 완료 기준에 맞게 작동한다 |

Claude 앱 **Code 탭**, Claude 채팅·Cowork, 터미널 Claude Code는 서로 다른 확인 대상이다. Codex 앱·CLI와 Hermes Desktop·CLI도 사용자가 작업할 화면을 기준으로 판정한다. 인증·모델·도구의 상태는 확인한 화면과 계정 범위에 연결해 기록한다.

## 완료 판정

각 필수 항목에 대상 앱·프로필·Agent-setup 버전, 관찰 결과, 상태(통과·실패·미확인)를 남긴다. 설치 파일의 존재, 연결 표시, 모의 시험, 실제 모델·도구 응답은 각각 구분한다. 수정한 항목은 현재 설치본에서 다시 확인한다.

필수 항목이 모두 적용·발견·동작 기준을 충족하면 해당 실행기를 **완료**로 보고한다. 실패·미확인·미해결 충돌이 있으면 **부분 적용**으로 보고하고 남은 항목을 적는다. Git 커밋·push 상태는 설치 완료 상태와 별도로 확인한다.
