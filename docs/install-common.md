# 설치 공통 기준 (AI용)

세 AI의 설치 안내가 공통으로 따르는 기준이다. 이 문서는 **무엇을** 갖춰야 하는지만 정한다. 설치·검증 방법은 그 컴퓨터의 OS와 이미 있는 도구를 보고 설치를 맡은 AI가 공식 문서를 확인해 고른다. 완료 판정에는 [설치 완료 기준](verification.md)을 적용한다.

## 진행 원칙

- 먼저 OS, 사용자 홈, 이미 설치된 AI 도구와 설정을 확인한다. 완료된 단계는 반복하지 않는다.
- 이미 있는 설정은 보존한다. 이 저장소의 설치기는 미리보기로 바뀔 내용을 먼저 보여 주고, 사용자가 고친 파일은 덮어쓰지 않는다. 충돌이 나오면 차이를 보여 주고 사용자의 결정을 받는다.
- Python·Node.js·uv·git 등 필요한 개발 도구는 대상 OS에서 호환되는 상태로 준비한다. 기존 도구와 사용자 설정을 보존하고, 설치 경로는 AI가 환경에 맞게 선택한다.
- 설치 시점의 공식 문서와 최신 안정판을 확인한다. 이 저장소에 기록된 버전은 마지막으로 검증한 출발점이다.
- 계정 로그인과 OS 권한 승인은 사용자가 한다. 비밀값은 대화나 저장소에 남기지 않는다.

## 공통으로 갖출 것

| 항목 | 기준 |
|---|---|
| Agent-setup 저장소 | 지울 필요 없는 지속 경로. 설치 기록이 이 경로를 원본 위치로 기억한다 |
| Python | 3.12 이상 (이 저장소의 설치기와 검사 실행) |
| CodeGraph | 코드 구조 탐색 MCP. 고른 AI의 MCP 설정에 등록. 색인은 작업할 Git 저장소에서 필요할 때 만든다 |
| GAM | AI 간 공유 장기기억 MCP. 고른 AI의 MCP 설정에 등록. 의미 검색용 Ollama 임베딩 모델 포함 |
| Aside | 브라우저 작업용 앱·CLI. 지원하지 않는 OS면 미설치로 보고. 브라우저 프로필은 사용자가 고른 것만 Aside 기본 가져오기로 |
| 전역 지침 | `shared/rules/`에서 만든 AI별 지침을 그 AI의 전역 지침 위치에 설치 |
| 스킬 | [스킬 표](skills.md)의 그 AI 열에 표시된 스킬 |

## 보고

설치한 것, 실제 동작을 확인한 것, 사용자가 해야 할 것(로그인·권한·결정)을 나눠 알린다. 경로는 그 컴퓨터의 실제 절대 경로로 적고, 확인하지 못한 항목은 미확인으로 남긴다. 필수 항목의 상태와 증거가 모두 채워질 때 완료를 보고한다.
