# Agent-setup Codex 작업 지침

- 이 폴더는 Agent-setup의 Codex 환경 구성 원본을 관리한다. 환경 연결 범위는 13-environment-components.md를 따른다. 제품 코드와 프로젝트별 지침은 해당 제품 저장소에서, 인증·대화·메모리는 비공개 사용자 데이터 경로에서 관리한다.
- 먼저 README와 05-change-management.md를 확인한다. 새 설치·포맷 후 구성은 10-new-machine.md, 스킬 선택은 03-skills.md, 모델·검증 기준은 11-working-method.md를 필요한 작업에서 읽는다.
- 설정·스킬 원본의 작성, 홈에 적용, 자동 발견, 실제 실행 검증을 구분한다. 전역 규칙의 정본은 ../shared/rules/이며 instructions/AGENTS.md는 ../scripts/build_rules.py가 만드는 설치 템플릿이다. 이 폴더 작업에는 루트 AGENTS.md와 이 문서를 적용한다.
- 사용자 홈 설정은 전체 복사·링크 교체하지 않는다. 비밀값·인증 파일·DB·캐시·프로젝트별 로컬 경로를 Git 후보나 보고서에 복사하지 않는다.
- 원격 변경은 현재 사용자가 요청하거나 승인한 범위에서만 수행한다.
- 로컬 커밋은 현재 요청 범위에서만 수행한다. 기존 사용자 변경과 원격 설정을 보존한다.
- 코드 동작을 바꾸지 않는 문서 작업에는 링크·구조 검증만 하고 제품 빌드를 실행하지 않는다.
- 실제 ~/.codex·~/.agents 적용, 기존 docs 이동, OMH·Hermes·Aside 제거는 현재 요청과 단계에 맞게 수행한다. 계획에 적혀 있다는 이유만으로 실행하지 않는다.
