# OMH 3.0.1 업데이트와 Agent-setup 채용·삭제 점검

2026-10-09. 검토 기준은 [OMH v3.0.1 릴리스](https://github.com/rlaope/oh-my-hermes/releases/tag/v3.0.1)와 태그 커밋 `532cc8f1a2b8d27c86a1b57f89448a976c7cde6e`이다. 내려받은 wheel의 SHA256은 `2750387eee094a2ef12dc9dd23bdbc08b0b24a3d08d08cf241cb9a715d02021e`로 릴리스 표기와 일치했다.

| 항목 | 처리 | 근거 |
|---|---|---|
| OMH v3.0.1 안정판 | 로컬 명령·관리 스킬 142개·플러그인 번들 적용, Agent-setup 참조 커밋 갱신 | 3.0.1의 메모리 회수 훅 순서, 스킬 검사 문구, 플러그인 실행 경계 수정 |
| 기존 사용자 라우팅 | 12개 분류 순서·추론과 Hermes 설정 유지 | 업데이트 후 후보를 다시 읽고 Hermes 설정의 변경 범위를 대조 |

| 업데이트 안내 | 명령 패키지 갱신과 스킬·플러그인 갱신을 순서대로 명시 | `omh update` 미리보기는 명령 패키지를 그대로 둠 |

## 확인 범위

- `omh --version`은 3.0.1을 표시했다. 관리 스킬 목록은 업데이트 전후 142개로 같았다.
- `omh setup`의 3.0.1 플러그인 갱신은 성공했다. Hermes의 간단한 플러그인 목록에서 `omh 3.0.1 enabled`를 확인했다. 설정 변경은 중복 스킬 경로 한 줄이었고 해당 줄을 제거해 기존 설정과 바이트 단위로 일치시켰다.
- OMH의 12개 분류 모델·추론 순서가 Agent-setup의 Claude 넉넉형 프리셋과 일치했다.
- `omh doctor`는 로컬 병합 스킬 7개에 따른 `local_modifications`·`guidance_projection` 두 항목을 남긴다. 플러그인 번들·훅 무결성 오류는 갱신 후 해소됐다.
- Hermes 명령은 `v0.21.5+6562.gb286002`를 표시했다. Hermes `main` 채널은 추가 업데이트를 안내하므로 별도 버전 전환이 필요할 때 다시 점검한다.
- 새 Hermes Desktop 세션의 플러그인 로딩, 제공자 호출, 실제 자식 위임은 이번 점검에서 관찰하지 않았다.

기존 설정과 로컬 스킬의 비공개 백업은 사용자 OMH 홈의 `backups/2026-10-09-before-3.0.1/`에 있다.
